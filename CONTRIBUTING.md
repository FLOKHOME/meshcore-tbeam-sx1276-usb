# Contributing

Thanks for helping owners of classic T-Beam boards use MeshCore over USB.

- Please open an issue for new hardware revisions, compiler issues or documentation corrections.
- Run `python -m unittest discover -s tests -v` before opening a pull request.
- Avoid bundling upstream MeshCore code or commercial firmware in this helper repository.
- Keep supported-board statements evidence-based: provide board marking, radio chip, display and USB interface details, working log, and upstream commit.
- Never paste private keys, repeater passwords, GPS home coordinates, serial tokens or access credentials.
- Changes to build flags must be tested against the pinned release and on the actual hardware before the README claims success.
- Use English code/comments and concise English documentation; German translations are welcome.

This project is a community helper, not an official MeshCore firmware distributor.
